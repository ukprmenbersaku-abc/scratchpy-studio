# ScratchPy Studio 使い方ガイド

---

## 1. これは何をするツール?

**ScratchPy Studio** は、Scratch のプロジェクトファイル(**.sb3**)と、
Python 風のテキスト言語 **ScratchPy**(スクラッチパイ)を**双方向に変換**する Web ツールです。

```
 .sb3(Scratch)  ──変換──▶  ScratchPy テキスト  ──変換──▶  .sb3(Scratch)
     「開く」                   編集・診断・整形                 「ダウンロード」
```

できること:

- Scratch の .sb3 を読み込んで、ScratchPy のコードとして表示・編集
- ScratchPy のコードを .sb3 としてダウンロード(Scratch / TurboWarp でそのまま開けます)
- 入力しながら**日本語のエラー・警告**をリアルタイム表示(型チェック付き)
- プログラムの構造ツリー、生成される project.json のプレビュー
- ワンクリック整形、サンプルプログラム 4 本を内蔵

変換と診断は**ブラウザ内**で行われます。AIアシスタントを使用するときだけ、確認・同意後にコード、会話、診断と言語仕様が選択したAI事業者に送信されます。画像・音声のファイル自体は送信しません。

## 3. クイックスタート(3 分)

1. **ツールを開く**と、サンプル「こんにちは ScratchPy!」が表示されています。
2. 右の **診断** タブを確認 → 「エラー・警告はありません」と出ていれば OK。
3. **.sb3 をダウンロード** をクリック → `project.sb3` が保存されます。
4. [Scratch エディタ](https://scratch.mit.edu/projects/editor/) で
   「ファイル → コンピューターから読み込む」(または [TurboWarp](https://turbowarp.org/) にドロップ)→ 動きます!
5. エディタのコードをいじって(例: `"こんにちは!"` を `"やあ!"` に)、もう一度ダウンロードしてみましょう。

## 3.5 Blockly ブロックエディタ

「ブロック」タブを開くと、現在のコードを Blockly のワークスペースで編集できます。

1. 左のカテゴリからブロックをドラッグし、ステージまたはスプライト内の適切な位置につなぎます。
2. 数値や文字をクリックすると入力できます。ホイールやツールバーで拡大・縮小できます。
3. 編集が終わったら **「コードに反映」** を押します。コード表示に切り替え、診断タブでエラーを確認できます。
4. 「再読み込み」は現在のコードからブロックを作り直します。未反映の編集がある場合は確認が出ます。

未接続ブロックや複数のステージがあると反映できません。構文エラーがあるコードや、Blockly で完全に保持できない構文を含むコードは、元のコードを守るため反映が無効になります。コードを直接編集してください。反映は自動ではなく明示的に行います。コードとブロックの両方を別々に編集した場合、ブロックを上書き適用することはできません。

カスタムブロックの呼び出しは、定義をコードへ反映したあと、再読み込みすると「マイブロック」に現れます。

## 3.6 AIアシスタント（通常版）

右の「AIアシスタント」から Gemini、OpenAI、Anthropic を選び、APIキーとモデルIDを入力します。データ送信と課金に同意してから、作りたい内容やエラーの修正を依頼してください。キーはブラウザのメモリーにのみ保持されますが、ブラウザ拡張や端末の利用者に見える可能性があります。共有端末での使用は避け、キーに権限・利用上限を設定してください。

AIの提案は構文・型・.sb3構造を検査し、エラーがあれば最大2回自動修正します。実行テストではありません。コードを確認した後に「エディターに適用」を押します。生成後に元コードが変わった場合や未反映のブロックがある場合、適用できません。Scratchで動作を確認し、元ファイルも残してください。各社の利用料金が発生し得ます。ブラウザ接続は事業者のCORS・組織設定により拒否される場合があります。

## 4. .sb3 を ScratchPy に変換する

方法は 2 つ:

- **.sb3 を開く** ボタン → ファイル選択
- **.sb3 ファイルをウィンドウにドラッグ&ドロップ**(画面が青くなったら離す)

変換されると:

- エディタに ScratchPy コードが表示されます
- ステータスバーに読み込んだファイル名が出ます
- **ログ** タブに変換の詳細(スプライト数・ブロック数・変換メモ)が記録されます

### 変換メモ(notes)の読み方

ログに次のようなメモが出ることがあります。**エラーではありません**:

| メモ | 意味 |
|---|---|
| `未対応ブロック: xxx → コメント行に変換されました` | ScratchPy に対応する書き方がないブロック(TurboWarp 拡張など)。コード内には `# [変換不可ブロック]` コメントとして残りますが、**もう一度 .sb3 に変換するとこの部分は失われます** |
| `ハットブロックなしの孤立したスクリプトはコメント化しました` | Scratch 上で「実行されないブロック」だったもの。コメントとして全文残ります |
| `値モニターは変換対象外のため無視しました` | タイマー表示などのモニター。変数・リストのモニターは変換されます |

### 元に戻したいとき

読み込んだ .sb3 の**画像・音はそのまま保持**されます。コードを編集して
「ダウンロード」すれば、元のアセットを使った .sb3 が生成されます
(コスチューム名・音名を変えなければバイト単位で同一です)。

## 5. ScratchPy の書き方(ミニチュートリアル)

詳しい仕様は `docs/01-scratchpy-language.md` へ。ここでは最短コースで:

### ① スプライトとイベント

```scratchpy
sprite Cat:
    costume costume1

    on flag:            # 緑の旗が押されたとき
        say("こんにちは!")
```

### ② 変数(型を書く!)

```scratchpy
stage:
    var score: int = 0 @show      # 画面に表示される整数変数

sprite Cat:
    on flag:
        score = 0
        score += 10               # score は int なので += できる
```

型が違うと**その場で赤いエラー**になります:

```scratchpy
var score: int = "りんご"   # ✗ エラー: int 型に str は代入できません
```

### ③ くり返しと条件

```scratchpy
on flag:
    repeat 10:
        move(10)
        if touching("edge"):
            bounce()
    while score < 100:
        score += 1
```

### ④ カスタムブロック(関数)

```scratchpy
sprite Cat:
    def jump(power: int):
        repeat power:
            change_y(10)

    on flag:
        jump(5)
```

### ⑤ リスト

```scratchpy
stage:
    list "取った果物": list[str] = [] @show

sprite Apple:
    on click:
        "取った果物".add("リンゴ")
        say(len("取った果物"))
```

## 6. タブパネルの使い方

### 診断

- エラー(!)/ 警告(▲)が一覧表示されます。**クリックすると該当行へジャンプ**します。
- エラーが 1 つでもあると ダウンロードボタンは無効になります(グレー表示)。
- 警告は変換自体はできます(例:「結果が使われていません」)。

### 構造

プログラムを木で表示します:

```
▼ ステージ  Stage          2 スクリプト
    変数  score: int       = 0 / 表示ON
    リスト  items: list[str]  3 要素
  ▼ スプライト  Cat         1 スクリプト
    ▼ イベント  on flag:    3 文
        move(10)
        ...
```

▶/▼ で折りたたみ・展開。「どのスプライトに何があるか」の把握に使えます。

### { } JSON

現在のコードから生成される **project.json(Scratch の内部形式)のプレビュー**です。
エラーがあると生成されません。.sb3 の中身を勉強したいときにどうぞ(→ `docs/02-sb3-format-analysis.md`)。

### ログ

変換・読み込み・ダウンロードの履歴。
.sb3 読み込み時の変換メモ(notes)や未対応ブロックの一覧もここに出ます。

## 7. よくある質問(FAQ)

**Q. ダウンロードした .sb3 が Scratch で開けません**
A. このツールは生成時に構造検証を行っています。それでも開けない場合は、
ログの検証警告を確認し、プロジェクト名を変えて保存し直してみてください。
(TurboWarp ではより寛容に読み込めます)

**Q. コメントは .sb3 に保存されますか?**
A. いいえ。ScratchPy のコメントは .sb3 往復で失われます。
逆に、.sb3 側の「吹き出しコメント」もテキストには取り込まれません。

**Q. 変換したらブロックが減りました**
A. ログを見てください。未対応ブロック(TurboWarp 拡張・「値を返すカスタムブロック」など)は
コメント行に変換され、再変換時に失われます。対応済み: 動き・見た目・音・イベント・制御・
センシング・演算・変数・リスト・マイブロック・ペン拡張。

**Q. 変数に型を付けたくないのですが…**
A. `var x: any = 0` とすると型チェックを緩められます。
また .sb3 から変換したときに型が衝突する変数は自動的に `any` になります。

**Q. クラウド変数は?**
A. `stage:` 内で `var "☁ 名前": int = 0 @cloud @show` のように書きます。数値型のみです。

**Q. 日本語の変数名は使えますか?**
A. はい。`var 点数: int = 0` のようにそのまま書けます。
空白や記号を含む名前は `var "my var": int = 0` のように引用符で囲みます。

**Q. ファイルはどこかに送信されますか?**
A. 通常の変換はブラウザ内で行われます。AIアシスタントを使う場合、同意のうえ現在のコード・会話・診断・言語仕様が選択した事業者へ送られます。APIキーはページのメモリーのみで保持し、アプリは保存しません。
